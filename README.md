AI Career Recommendation System

A simple AI-based recommendation system developed as part of the DecodeLabs Internship - Project 3: AI Recommendation Logic. This project recommends suitable career paths and skills based on a user's interests and skill level.

Project Objective

The goal of this project is to build a basic recommendation system that:
- Takes user preferences as input
- Matches preferences using recommendation logic
- Suggests relevant career paths
- Recommends skills to learn
- Demonstrates fundamental AI recommendation concepts
 
Features
User-friendly command-line interface
Career recommendations based on interests
Skill-level based suggestions
Personalized learning paths
Rule-based recommendation engine
Easy to understand and modify

Technologies Used
-Python 3
-Dictionaries
-Conditional Statements
-Pattern Matching Logic
